TaskManagerPlus

A free, offline process viewer and task manager replacement for Windows.

Getting started
---------------
Run SystemInformer.exe (64-bit Windows 10 or later). No installation is
needed. The plugins folder must stay next to the executable.

Settings
--------
Settings and plugin data are stored in %APPDATA%\TaskManagerPlus. To keep
them next to the executable (for example on a USB drive), create a blank
file named settings.json in the same folder as SystemInformer.exe.

Plugins
-------
Plugins can be configured from the Options dialog, Plugins tab. Disk and
firewall information from the ExtendedTools plugin requires running with
administrator rights.

See README.md for features, the offline guarantee and build instructions, and
