TaskManagerPlus changelog

Unreleased (0.1.0)
 * Fork of System Informer with a calmer default interface and light, dark and
   OLED themes.
 * New plugins: Process Rules, Startup Manager, Process History.
 * Affinity dialog: P-core and E-core presets.
 * Removed all network functionality (updater, online checks, network tools,
   reverse DNS, revocation lookups, default symbol server).
 * Own identity: settings in %APPDATA%\TaskManagerPlus (migrated once from an
   existing System Informer folder), own single-instance and object names.
 * Task Manager replacement (Options) with repair of a stale path at startup.
